# Tracking (follower and sub goal bars, trackers) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A follower goal bar and a sub goal bar (each its own OBS source, managed like the tip goal, with lifetime / calendar / rolling / hours periods) and six tracker sources (latest follower, sub, tip, raid, bits; top tipper this stream), all managed from a new `/dashboard/tracking` page.

**Architecture:** Follow and sub events from EventSub are also written to a new long-lived record (`tracking_events`); goals count from that record (or from Twitch totals for lifetime) through pure period helpers; trackers keep their last value in `tracker_values`. Each source is an SSE stream on its own bus channel, rendered by one new page script that reuses the tip goal bar's card. The live poller also checks every enabled streamer's own channel, which gives "this stream" its start.

**Tech Stack:** Node 24, Express 5, EJS, better-sqlite3, plain browser JS, `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-16-tracking-design.md` (its "Decisions after the builder check" section settles calendar rollover, rolling goals, sub counting, trackers' storage, account changes and non-Affiliates).

## Global Constraints

- `CLAUDE.md` rules: CommonJS, no build step, no `require()` in EJS; all SQL in `src/db.js`; every user-facing text through `t()` in all 7 locales (`scripts/locale-keys.js add` then `set <lang>`); JSON embeds end in `.replace(/</g, '\\u003c')`; CSRF on every POST (`header.ejs` pages get it for free); every outbound fetch has `AbortSignal.timeout()`; in-memory maps get an `.unref()`'d sweeper; new streamer columns go through the ALTER loop; new streamer-owned tables go in `STREAMER_OWNED_ROWS`.
- New OBS sources never use bus channel `overlay:<id>`; they follow the tip goal source in `src/routes/overlay.js` (`getStreamerByOverlayToken`, SSE with a 30 s heartbeat, `holdStream`, `endStreamWhenAccountDisabled`, `type:'config'` first).
- Goal bar look = the tip goal card (`public/overlay/goal.css`): `.goal-card`, `--goal-color`, accent line, title + "current / target", stripes, `+N` pop, confetti and glow on reaching.
- Limits: title ≤ 60 characters; target 1–10,000,000 (whole numbers); colour `#rrggbb`; hours 1–720; follower read-back at most 5,000 followers (50 pages of 100); record kept 400 days; lifetime re-read at most every 10 minutes per goal while a source is open, and when the goal starts.
- Periods: `lifetime`, `year`, `month`, `week`, `day`, `hours`; mode `calendar` (weeks start Monday, in the goal's IANA time zone) or `rolling` (365, 30, 7, 1 days) for year/month/week/day.
- `features.overlays` off: `/dashboard/tracking` redirects to `/dashboard` (`overlayPage`), and the OBS overlay card's link to it is hidden.
- Unit suite: `node --test "src/**/*.test.js" "tests/**/*.test.js" "bridge/test-*.js"` green at the end of every task.

## Review Focus

1. **Calendar rollover at a time-zone boundary** (a monthly goal in `America/Los_Angeles` at 23:59 local on the 31st; a DST-change day): the period start/end match local midnight — pinned in Task 1.
2. **A re-follow inside the window** counts once; a gift of 5 counts 5 — pinned in Task 2.
3. **A restart or OBS reload** shows the same goal number and the same tracker values — pinned in Tasks 4 and 6.
4. **A broadcaster token without `moderator:read:followers`, or a non-Affiliate channel**: the goal shows "Reconnect Twitch" / "not available", never 0 — pinned in Tasks 3 and 4.
5. **Linking a different Twitch account** ends active goals and clears trackers — pinned in Task 8.
