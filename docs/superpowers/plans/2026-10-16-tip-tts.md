# Tips read aloud (ElevenLabs TTS) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tips paid through the Atleta tip page at or above the streamer's threshold are read aloud in OBS by an ElevenLabs voice the streamer chose, in a line the streamer wrote, within a monthly character budget on Atleta's account.

**Architecture:** A pure line builder (`tipSpeech.js`) decides whether and what to read; an ElevenLabs client (`elevenLabs.js`) turns the line into an MP3; an orchestrator (`tipVoice.js`) runs per streamer, one tip at a time — gates, reserves characters, makes the audio, then emits the donation alert with `tts` attached (the alert waits for its voice, at most 15 s). The OBS overlay plays the voice after the alert's own sound and keeps the alert on screen until it ends. Settings live on `streamers` columns, edited on `/dashboard/donations`.

**Tech Stack:** Node 24, Express 5, EJS, better-sqlite3, plain browser JS, `node --test`; ElevenLabs REST (`POST /v1/text-to-speech/{voice_id}`, `GET /v1/user/subscription`).

**Spec:** `docs/superpowers/specs/2026-10-16-tip-tts-design.md`

## Global Constraints

- Only PayPal tips through `/tip/:username`, only a new recorded capture (`logDonation()` → true). StreamElements, Bits, subs, YouTube, chat: never read.
- Off by default (`tts_enabled` 0). Default threshold 5 in the tip page's currency (`streamers.donation_currency`); a tip in another currency is not read.
- Read only when: TTS on; amount ≥ threshold; `overlay_enabled` and `overlay_donation_enabled` on; an alert overlay open (`overlayPresence.isOpen`); the line fits the streamer's remaining monthly characters; the account's remaining credits ≥ `TTS_CREDIT_FLOOR` (default 20000). Otherwise the alert fires at once, as today, and nothing is sent to ElevenLabs.
- Line: a template with `{name}`, `{amount}`, `{message}` (≤ 200 characters); defaults "{name} tipped {amount}: {message}" and, without a message, "{name} tipped {amount}!" in the chosen language. Name and message: links removed, runs of the same character cut to 3; the message cut to 200 characters. A message hitting the streamer's banned words is not read (no-message variant); a name hitting them, or empty, is a locale "Someone".
- Limits: 15,000 characters per streamer per calendar month (UTC), counted as the full line sent, reserved before the request, kept when it times out; a line that would pass the limit is skipped, never cut. An admin can set one streamer's limit.
- The alert waits for its voice: one 15-second deadline for the audio; on failure the alert is emitted without it. One tip at a time per streamer.
- Overlay: the voice at overlay volume × `tts_volume`, starting 1 s into the alert (after its sound); the alert stays for max(its hold, 1 s + voice + 0.3 s), at most 30 s.
- Audio files at `data/tts/<streamerId>/<uuid>.mp3`, served at `/overlay/tts/:token/:file` with `userContentHeaders.js`'s headers, removed after one hour.
- `donations.tts_status` ∈ `read`, `below_threshold`, `other_currency`, `blocked_off` (overlay or donation alert off), `overlay_closed`, `limit`, `failed`, or NULL (TTS off); shown in the donation history.
- Test the voice: a sample at the threshold amount, cleaned like a real tip, played in the page and in OBS when open; counts toward the limit; its own 10-second cooldown (`createTestCooldown({ cooldownMs: 10000 })`).
- `ELEVENLABS_API_KEY` is read only on the server; unset → the settings section says it is not available and nothing is read. Every outbound call has `AbortSignal.timeout()`. Tests never touch the network.
- Every text in all seven locales (`node scripts/locale-keys.js add|set`); all SQL in `src/db.js`; plain CommonJS, no build step.
- Unit suite: `node --test "src/**/*.test.js" "tests/**/*.test.js" "bridge/test-*.js"` passes at the end of every task.

## Review Focus

1. **Two tips land in the same second** for one streamer: both are read, in order; the second's alert waits for the first's — pinned in Task 5 (`queue keeps tips in order`).
2. **ElevenLabs hangs**: the alert still appears within ~15 s, without a voice, status `failed`, the reserved characters stay counted — pinned in Task 5.
3. **A tip near the end of the monthly budget**: a line longer than what is left is skipped (status `limit`), a shorter later one is read — pinned in Task 2 (`reserveTtsCharacters`) and Task 5.
4. **Hostile text** (a donor name like `evil.com`, `aaaaaaaaaa`, emoji floods, markup, a `{name}` typed by the donor): nothing of a link is spoken, runs are cut, no placeholder is filled twice — pinned in Task 1.
5. **The voice outlives its alert** (OBS reloads, Clear All): Clear All cancels a pending voice, and an expired or foreign file answers 404 — pinned in Task 6 and Task 5.

### Task 1: The line builder (pure)

**Files:**
- Create: `src/services/tipSpeech.js`, `src/services/tipSpeech.test.js`

**Interfaces:**
- Produces:
  - `MESSAGE_MAX = 200`, `TEMPLATE_MAX = 200`, `RUN_MAX = 3`
  - `cleanSpeech(text) -> string`: tokens `chatFilters.containsLink()` flags removed, runs of one code point longer than 3 cut to 3, control characters removed, whitespace collapsed, trimmed.
  - `spokenAmount(amount, currency, lang) -> string`: at most two decimals, ".00" dropped, the language's decimal separator, then the currency's spoken name (locale `tts.currency.<CODE>.one` / `.other`): `(25,'EUR','en')` → `'25 euros'`, `(1,'USD','en')` → `'1 dollar'`, `(12.5,'EUR','pt')` → `'12,50 euros'`.
  - `buildLine({ template, emptyTemplate, name, amountText, message }) -> string`: fills `{name}`, `{amount}`, `{message}` in one pass (a donor's `{name}` is never filled again — the rule of `chatTemplate.js`); an empty `message` uses `emptyTemplate`.
  - `speechDecision({ streamer, donation, overlayOn, alertOn, overlayOpen }) -> { read, status }`, checked in this order: TTS off → `{ read:false, status:null }`; `donation.currency !== streamer.donation_currency` → `other_currency`; `amount < tts_min_amount` → `below_threshold`; overlay or donation alert off → `blocked_off`; overlay not open → `overlay_closed`; else `{ read:true, status:null }` (limits come in Task 5).
  - `defaultTemplates(t, lang) -> { template, emptyTemplate }`: `t(lang, 'tts.template.default', { name: '{name}', amount: '{amount}', message: '{message}' })` and the same for `tts.template.empty` (the locale texts use `{{…}}` like every locale text; filling them with single-brace placeholders yields the stored form).
  - `prepareSpeech({ streamer, donation, t, bannedCheck }) -> { text, messageRead }`: `cleanSpeech` on name and message, message cut to 200; `bannedCheck(text)` truthy on the message → `messageRead:false` and the no-message template; on the name (or an empty name) → `t(lang,'tts.someone')`; the streamer's templates, else `defaultTemplates`; `lang = streamer.tts_language || 'en'`.
